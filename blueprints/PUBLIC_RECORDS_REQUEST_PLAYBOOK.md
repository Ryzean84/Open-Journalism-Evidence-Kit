# Blueprint: Public Records Request Playbook

**Global framework v0.1. Laws and procedures vary by jurisdiction. This is not legal advice.**

## Before making a request
1. Identify the public body likely to hold the record.
2. Confirm the current access-to-information law, scope, deadlines, fees, appeal route, and exemptions.
3. Narrow by subject, date range, record type, office, and format.
4. Ask for existing records, not answers to broad questions or newly created analysis.
5. Consider privacy, safety, and risks of exposing sources or vulnerable people.
6. Keep a copy of the request and proof of delivery.

## Request template

**To:** [Public records / information officer]  
**Subject:** Request for access to public records — [specific topic]

I request access to the following existing records held by [public body]:

- Record types: [emails / contracts / minutes / reports / datasets / policies]
- Subject: [narrow description]
- Date range: [start] to [end]
- Relevant office or program: [office]
- Preferred format: [searchable electronic format, if available]

If any portion is withheld, please identify the legal basis and release reasonably separable non-exempt portions where the law permits. If the request is too broad, please contact me to discuss narrowing it.

Please advise in advance if fees may exceed [amount]. I would appreciate acknowledgement and the applicable reference number.

Sincerely,  
[Name or permitted contact identity]

## Follow-up sequence
- Record acknowledgement and agency reference number.
- Calendar statutory response date only after checking current local law and valid extensions.
- Clarify scope if requested.
- Review released records for completeness, redactions, dates, and attachments.
- If denied or delayed, check local appeal/review procedure and deadlines.
- Record communications and decisions.
- Publish request and response only after privacy, safety, and rights review.

## Global adaptation requirement
Every jurisdiction-specific version must identify the current statute/regulation, official oversight body, request channel, appeal route, deadlines, fees, language-access provisions, and date last checked. Never copy deadlines from another country or state.
